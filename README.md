# HUNTHUB - Digital Craftsmanship & Luxury Mobile Marketplace

Developed by **Tonmoy Bora**.

## 🌟 Overview
**HuntHub** is an ultra-luxurious, modern web application built for digital craftsmanship, phone sales, and pre-owned device trading.

### Key Features:
- **Cinematic Starting Intro**: Animated text reveal: *"WELCOME TO HUNTHUB DEVELOPED BY TONMOY BORA"*
- **WhatsApp Concierge Purchasing**: Instant buy & checkout redirection to **+91 7086869464**
- **Curated Collections & Exclusive Edition**: High-fashion product showcase with scroll reveal animations
- **User Phone Selling Request System**: Pre-owned phone submissions sent to Admin review queue
- **Auto Photo Changer Lightbox Modal**: Interactive fullscreen gallery with 3.5s slideshow timer & thumbnail tray
- **Dedicated Admin Control Panel (`/admin`)**:
  - Review user device submissions
  - Set custom store retail price (adding profit margin)
  - Approve & publish requests live to the store
  - Full product inventory editor (Edit photos, prices, descriptions, titles)
- **Selections Cart**: Dynamic subtotals, quantity adjustments, clear all, and removal actions

## 🚀 Deployment on Vercel
This project is configured for seamless deployment on **Vercel**:

1. Log into [Vercel](https://vercel.com/) and click **Add New Project**.
2. Select the GitHub repository: `https://github.com/tonmoyvlog787-collab/HUNTHUB.git`
3. Framework Preset: **Other / Plain HTML**
4. Root Directory: `./`
5. Click **Deploy**!

### Vercel Route URLs:
- **Public Main Store**: `https://<your-project>.vercel.app/`
- **Dedicated Admin Portal**: `https://<your-project>.vercel.app/admin` or `https://<your-project>.vercel.app/admin.html`
